# About

## What is this?

[PokeApi](https://central.sonatype.com/artifact/fr.tykok/pokeapi) is a Kotlin library that wraps
[pokeapi.co](https://pokeapi.co/): you ask for an entity type, it resolves the endpoint, performs the
request and maps the JSON into a data class. This site is its documentation.

## Under the hood

| | |
| --- | --- |
| Language | Kotlin 2.1, targeting JVM 17 |
| HTTP | [OkHttp](https://square.github.io/okhttp/) |
| JSON | [Jackson](https://github.com/FasterXML/jackson-module-kotlin) (`jackson-module-kotlin`) |
| API docs | [Dokka](https://kotl.in/dokka), published on [javadoc.io](https://javadoc.io/doc/fr.tykok/pokeapi) |
| This site | [MkDocs](https://www.mkdocs.org/) with [Material](https://squidfunk.github.io/mkdocs-material/) |
